# Aplikasi Konversi Suhu

Program sederhana berbasis GUI (Java Swing) untuk mengonversi nilai suhu dari satu skala ke skala lainnya.  
Aplikasi ini dibuat menggunakan NetBeans.

## 🔧 Fitur Utama
- Input nilai suhu melalui JTextField
- Pilihan skala asal: Celcius, Fahrenheit, Kelvin, Reamur
- Pilihan arah konversi menggunakan JRadioButton
- Tombol Konversi untuk menampilkan hasil
- Validasi input agar hanya angka yang bisa dimasukkan
- Konversi otomatis ke berbagai skala suhu

## 🧠 Cara Menggunakan
1. Jalankan program KonversiSuhu.java
2. Masukkan nilai suhu yang ingin dikonversi
3. Pilih skala asal dari daftar ComboBox
4. Pilih skala tujuan melalui RadioButton
5. Tekan tombol **Konversi**
6. Hasil konversi akan muncul di bawah dan melalui JOptionPane
